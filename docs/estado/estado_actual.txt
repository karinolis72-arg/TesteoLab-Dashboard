🔧 PRÓXIMO PASO (CUANDO REGRESES)
═══════════════════════════════════════════════════════════════════════════════

PASO 1️⃣: Ejecutar script PowerShell (2 minutos)
───────────────────────────────────────────────
1. Abre PowerShell como Administrador
2. Navega a C:\apptesteo
3. Ejecuta:

   cd C:\apptesteo
   .\FIX_GIT_AND_PUSH.ps1

Este script:
   ✓ Limpia el repositorio Git corrupto
   ✓ Crea nuevo repositorio Git limpio
   ✓ Hace commit de todos los archivos
   ✓ Hace push a GitHub
   ✓ Te pide credenciales (usar Personal Access Token)

PASO 2️⃣: Crear Web Service en Render (3 minutos)
─────────────────────────────────────────────────
1. Ve a https://render.com/dashboard
2. Click "New +" → "Web Service"
3. Conectar repo: TesteoLab-Dashboard
4. Configurar como se detalla en QUICK_START_RENDER.md
5. Agregar NOTION_TOKEN en variables de entorno
6. Click "Create Web Service"
7. Esperar 2-3 minutos hasta que diga "Live"

PASO 3️⃣: Verificar (1 minuto)
────────────────────────────
1. Copiar URL de Render (ej: testeolab-dashboard.onrender.com)
2. Abrir en navegador desde PC
3. Abrir en navegador desde celular
4. Verificar que funciona

⚠️ IMPORTANTE - CREDENCIALES
═══════════════════════════════════════════════════════════════════════════════

El script pedirá autenticación GitHub:
   • Username: tu-usuario-github
   • Password: [Personal Access Token, NO la contraseña de GitHub]

Si no tienes PAT:
   1. Ve a https://github.com/settings/tokens
   2. Click "Generate new token (classic)"
   3. Dale permisos: repo, write:repo_hook
   4. Copia el token
   5. Úsalo como "password" cuando git lo pida
