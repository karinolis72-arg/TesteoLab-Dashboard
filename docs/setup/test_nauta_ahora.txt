❌ SI ALGO FALLA
═══════════════════════════════════════════════════════════════════════════════

Error: Dashboard no carga
  → Verifica: python notion_api.py está corriendo
  → URL correcta: http://localhost:5000

Error: Dashboard se recarga constantemente
  → Abre Console (F12)
  → Busca errores en rojo
  → Refresca la página (Ctrl+Shift+R)

Error: No veo módulo NAUTA
  → Recarga la página con Ctrl+Shift+R
  → Verifica que veas "🤖 NAUTA" en la página

Error: Modal no abre
  → Abre Console (F12)
  → Busca "Error opening modal" o similar
  → Verifica que JavaScript no tiene errores

Error: No puedo guardar cierre
  → Asegúrate de completar TODOS los campos:
    ✓ Al menos 1 checkbox
    ✓ Alguna nota (no puede estar vacío)
    ✓ Energía seleccionada (no "--")
  → Abre Console y mira la request POST
