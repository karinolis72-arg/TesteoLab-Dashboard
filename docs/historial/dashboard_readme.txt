2. python3 run_dashboard.py
3. http://localhost:9000

📱 ACCESO DESDE CELULAR (WiFi):
───────────────────────────────
1. Asegúrate que compu y celular estén en mismo WiFi
2. En la compu, ejecuta: ipconfig (Windows) o ifconfig (Mac)
3. Busca "IPv4 Address" (algo como 192.168.1.x)
4. En celular abre: http://[ESE_IP]:9000
