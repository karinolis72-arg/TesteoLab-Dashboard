1. ✅ MÓDULO NAUTA EN DASHBOARD
   └─ Ya NO es una página separada
   └─ Es un panel dentro del dashboard_v2.html
   └─ Muestra estado del día: Tareas, Completadas, Energía

2. ✅ 3 BOTONES EN MÓDULO NAUTA
   ├─ 📖 VER BRIEFING (8:30 AM)
   ├─ 🌙 REGISTRAR CIERRE (21:30)
   └─ 📊 VER ÚLTIMO CIERRE

3. ✅ 3 MODALES SUPERPUESTOS
   ├─ Modal Briefing → Abre al click [VER BRIEFING]
   ├─ Modal Cierre → Abre al click [REGISTRAR CIERRE]
   └─ Modal Último Cierre → Abre al click [VER ÚLTIMO CIERRE]

4. ✅ FORMULARIO DE CIERRE
   ├─ Checkboxes: ¿Qué completaste?
   ├─ Textarea: Notas personales
   ├─ Select: Energía para mañana
   └─ Botón [GUARDAR CIERRE]

5. ✅ FUNCIONES JAVASCRIPT
   ├─ openBriefingModal()
   ├─ closeBriefingModal()
   ├─ openCierreModal()
   ├─ closeCierreModal()
   ├─ guardarCierre()
   ├─ openLastCierre()
   ├─ closeLastCierreModal()
   └─ loadNautaStatus()

6. ✅ ENDPOINTS API NUEVOS
   ├─ GET /api/nauta/status → Retorna estado actual
   ├─ POST /api/nauta/save-cierre → Guarda el cierre
   └─ GET /api/nauta/last-cierre → Obtiene último cierre

7. ✅ SCHEDULER (YA EXISTÍA)
   ├─ 8:30 AM → Genera datos de briefing
   └─ 21:30 → Genera template de cierre

────────────────────────────
http://localhost:5000

Deberías ver:
  ✓ Módulo NAUTA en el dashboard
  ✓ Estado: X Tareas, X Completadas, X% Energía
  ✓ 3 botones de acción

PASO 3: Prueba los botones
────────────────────────────

A) Click [📖 VER BRIEFING]
   Resultado esperado:
   ✓ Modal se abre
   ✓ Muestra título "NAUTA BRIEFING"
   ✓ Muestra tareas, hábitos, rueda de vida
   ✓ Click [X] cierra el modal
   ✓ Vuelves al dashboard

B) Click [🌙 REGISTRAR CIERRE]
   Resultado esperado:
   ✓ Modal se abre con formulario
   ✓ Muestra checkboxes de tareas del día
   ✓ Área de notas
   ✓ Select para energía

   Completa:
   1. Checkea 2-3 tareas
   2. Escribe una nota
   3. Selecciona "Alta" en energía
   4. Click [GUARDAR CIERRE]

   Resultado:
   ✓ Alert: "✅ Cierre guardado en Notion"
   ✓ Modal se cierra
   ✓ Vuelves al dashboard

C) Click [📊 VER ÚLTIMO CIERRE]
   Resultado esperado:
   ✓ Modal se abre
   ✓ Muestra los datos que acabas de guardar
   ✓ Score: X completadas / Y tareas
   ✓ Tus notas
   ✓ Energía registrada
   ✓ Click [X] cierra
